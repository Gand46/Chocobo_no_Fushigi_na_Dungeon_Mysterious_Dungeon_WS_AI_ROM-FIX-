Procedencia y límites

Las pruebas de guardado seleccionan de forma sintética la pantalla de escalera y después usan la confirmación y copia nativas. El equipo se prepara sintéticamente; el jefe recibe ayuda explícita. Las imágenes y estados iniciales fueron los mismos para ambas ROM. Estas ejecuciones confirman las rutas ensayadas, sin demostrar un recorrido natural completo, otro emulador ni hardware.

Reproducción

verify_regression.py comprueba hashes, límites binarios, escrituras y capturas desde los registros incluidos y las ROM reconstruidas con las fuentes HF20. El archivo JSON enumera los 89 controles. No se modificó la ROM en esta fase.

Fuente y créditos de la traducción base

La versión inglesa v1.1 usada como base corresponde a Chocobo's Dungeon for WonderSwan en Romhacking.net. Según el readme original conservado: SpecialAgentApe — hacking, traducción de menús y edición gráfica; Higsby — traducción; ShinxHijinx — pruebas; wowjinxy — agradecimiento especial. La receta editable actual es una reconstrucción de este proyecto, no el código fuente del equipo original. Procedencia y créditos completos.
